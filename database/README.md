# Banco de Dados

Esta pasta concentra scripts, migrations, views e demais artefatos relacionados ao banco de dados do projeto.

## Estratégia

- Firebird: origem operacional legada.
- Supabase/PostgreSQL: camada de dados moderna.
- Scripts de migração e sincronização devem ser versionados.
- Alterações estruturais devem ser acompanhadas de documentação.

Os scripts serão adicionados conforme o schema real seja levantado e validado.
